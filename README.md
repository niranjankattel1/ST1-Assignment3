# Project Documentation

## Overview
This project processes and classifies images of stream macroinvertebrates using machine learning.

## Classes
- **DataLoader**: Loads and splits dataset.
- **ModelTrainer**: Trains ML models.
- **Evaluator**: Evaluates model performance.
- **ConfigManager**: Manages configuration.
- **Visualizer**: Handles visualizations.

## Usage
Run `main.py` to execute the pipeline.
